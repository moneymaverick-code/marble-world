# 마블 월드

주사위를 굴려 세계를 여행하는 3D 보드게임이에요.
도시를 사고 건물을 짓고, 랜드마크를 세워요.
1~4명이 함께 놀아요. 사람끼리도, 컴퓨터(CPU)와도 돼요.
판은 세 가지예요. 세계 여행 · 세계 랜드마크 · 대한민국 일주.
갤럭시(안드로이드)와 PC(윈도우) 둘 다 돼요.

> 게임 코드는 이 저장소에 없어요.
> 여기는 설치 파일을 받는 곳이에요.

## 받기

- 갤럭시(안드로이드): https://github.com/moneymaverick-code/marble-world/releases/latest/download/marble-world.apk
- PC(윈도우): https://github.com/moneymaverick-code/marble-world/releases/latest/download/marble-world-setup.exe

두 주소는 늘 가장 새 판을 받아요.
바뀐 내용은 [Releases](../../releases/latest) 에 적어 둬요.

## 우리 집 다른 게임

첫 화면의 **다른 게임** 단추를 누르면 미니게임·상상월드·스카이 에이스로 바로 가요.
깔려 있으면 그 게임이 열리고, 없으면 받는 곳이 열려요.

## 업데이트

같은 받기 주소에서 새 파일을 받아 **덮어 설치**하면 돼요.
지우지 않고 덮어 설치하면 저장(이어하기·코인·꾸미기)이 그대로 이어져요.

## 갤럭시 설치 방법

1. 폰 인터넷에서 위 갤럭시 받기 주소를 열어요.
2. 받기가 끝나면 알림이나 **내 파일 → 다운로드** 에서 `marble-world.apk` 를 눌러요.
3. "출처를 알 수 없는 앱" 안내가 뜨면 **설정 → 이 출처 허용** 을 켜고 뒤로 와요.
4. **설치** 를 눌러요.
   "Play 프로텍트" 경고가 뜨면 **세부정보 더보기 → 무시하고 설치** 를 눌러요.
   (가게에 올린 앱이 아니라서 뜨는 안내예요.)
5. 끝나면 **열기**. 가로 화면으로 놀아요.

## PC 설치 방법

1. 위 PC 받기 주소에서 `marble-world-setup.exe` 를 받아요.
2. 받은 파일을 두 번 눌러요.
   "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 눌러요.
   (서명된 회사 프로그램이 아니라서 뜨는 안내예요.)
3. 관리자 권한 없이 내 계정에만 깔려요(`내 폴더\AppData\Local\Programs\MarbleWorld`).
4. 바탕화면의 **마블 월드** 로 켜요.

## 광고·결제·추적

- 광고 없어요.
- 실제 돈 결제 없어요. (게임 안 '코인'은 게임하면서 모으는 놀이 돈이에요.)
- 게임이 따로 사용 기록을 모아 보내지 않아요.
  게임이 인터넷을 쓰는 건 '다른 게임' 목록을 하루 한 번 받을 때뿐이에요.
